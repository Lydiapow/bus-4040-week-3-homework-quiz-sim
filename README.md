# bus-4040-week-3-homework-quiz-sim

## What type of quiz did I create?

I created a 20-question quiz based on the course material from Weeks 1–3. It includes both multiple-choice and true/false questions. The quiz gives immediate feedback, explanations, the week the question came from, and allows me to retry questions I missed.

## What worked?

The AI was able to create a working quiz in one HTML file. I was able to open the index.html file directly on my computer and take the quiz without needing a server or internet connection. The scoring and feedback features worked well.

## What did not work?

I had some difficulty getting the actual index.html file saved in the correct project folder at first. I also had to make sure the quiz was using the correct course materials and not other information.

## Did I have to make adjustments?

Yes. I had to make sure the correct Week 1–3 materials were available to the AI and then test the quiz through the actual index.html file. This showed me that AI can create something quickly, but I still need to check that the final product works correctly.

## How could I apply this to other activities?

I could use the same process to create study tools for other classes, such as practice tests, flashcards, or review games. I could also use AI to create simple tools for other projects by giving it clear instructions and checking the results.
